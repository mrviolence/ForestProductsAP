# Forest Supplies - Premium Timber & Forest Products

A modern, responsive website for a sustainable forestry business built with Next.js, React, Tailwind CSS, and Framer Motion.

## 🌳 Features

- **Responsive Design** - Mobile-first approach that works on all devices
- **Smooth Animations** - Beautiful transitions using Framer Motion
- **Modern UI** - Clean, professional design with custom color scheme
- **SEO Optimized** - Meta tags and structured data for search engines
- **Performance** - Optimized for fast loading and smooth interactions

## 📋 Sections

1. **Navigation** - Responsive header with mobile menu
2. **Hero** - Eye-catching landing section
3. **About** - Company story and statistics
4. **Services** - Core offerings (Timber, Firewood, Tree Planting, etc.)
5. **Nursery** - Tree species and seedling showcase
6. **Projects** - Portfolio of completed and ongoing projects
7. **Testimonials** - Client reviews and ratings
8. **FAQ** - Frequently asked questions
9. **Sustainability** - Environmental commitment
10. **Gallery** - Image showcase
11. **Blog** - Articles and insights
12. **Contact** - Contact form
13. **Footer** - Company information

## 🚀 Getting Started

### Installation

```bash
git clone https://github.com/mrviolence/ForestProductsAP.git
cd ForestProductsAP
npm install
npm run dev
```

Visit `http://localhost:3000`

### Production Build

```bash
npm run build
npm start
```
